# 顾问如何扩大影响力

想扩大影响力，可以先想清楚一个问题：你希望别人遇到什么难题时，会想到你？

“我能提供专业咨询”还不够具体。不妨把它写成一句话：我帮助哪类人，在什么情况下，解决什么问题。

接下来，可以从三个方向着手。

**一、把结论写成别人能用的判断方法。**

分享观点时，多解释一步：这个判断适用于什么情况？需要哪些信息？什么情况下不适用？让读者能对照自己的问题，而不只是记住一句话。

**二、让经验有依据，也有边界。**

写案例时，交代背景、采取的行动和观察到的结果。引用他人的研究，注明出处；使用假设场景，明确说明。没有证据的地方，保留不确定性。

**三、每次只讲透一个问题。**

从客户经常提出的一个疑问开始，说清楚你的判断，再给读者一个可以尝试的下一步。不必在一篇短文里展示全部专业知识。

下一次分享前，检查三件事：读者知道你能帮谁吗？看得懂你的判断依据吗？读完知道可以做什么吗？

可以先从一篇回答真实问题的小文章开始。
