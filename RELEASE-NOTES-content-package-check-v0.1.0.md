# Content package checker 0.1.0

2026-10-10 maintenance update to BBQ Growth Playbook, by BBQ / BBQ Growth Lab.

Adds a standard-library offline Python tool for checking complete draft mappings, exact source excerpts, byte hashes and inactive-claim dependencies. Includes two unposted channel demonstrations from BBQ's content map, deliberately incomplete/withdrawn examples, bilingual usage instructions and actual test reports.

The checker reports structural errors and affected drafts. It never approves semantic accuracy or publication. Existing Skill v0.3.0, its ZIPs, experimental status and separately recorded Codex/WorkBuddy results are preserved. No new marketplace submission, platform compatibility result, reader-use success, SEO improvement or AI citation result is claimed.
