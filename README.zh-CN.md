## 使用方式

先看示例，再填入原文、目标读者、渠道和语言。让代理读取 SKILL.md 后执行，并对照原文核对结果。Skill 的说明为英文，可按请求输出中文或英文；多语言质量仍需逐次核对。

Codex 项目级目录为 `.agents/skills/`，用户级目录为 `~/.agents/skills/`。放置前检查是否有同名目录，具体使用入口参照[当前官方说明](https://learn.chatgpt.com/docs/build-skills)。本项目没有替你登录或授权发帖。
