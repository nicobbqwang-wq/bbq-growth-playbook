# Illustrative output

Author-written demonstration only; not an automated compatibility test and not a published LinkedIn post.

## Draft

A useful article can answer several questions. A useful LinkedIn post usually needs one.

Before shortening an article, choose the reader's question.

Then keep:

- One takeaway that helps them make a decision.
- The explanation or example needed to use it.
- Any condition that changes when the advice applies.

Adjust the context and level of detail for the channel. Keep the evidence attached to the claim.

The post should be useful on its own. A link can offer the fuller explanation.

Try this with one article: which single question could you help a reader answer today?
